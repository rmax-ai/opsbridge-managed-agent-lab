# Incident Severity Model

| Severity | Definition | Examples | Response Time |
|----------|-----------|----------|---------------|
| SEV1 | Customer-facing outage, data loss, or revenue impact | API down, payment failures, data corruption | Immediate |
| SEV2 | Service degraded, partial functionality loss | Elevated latency, feature unavailability | 30 min |
| SEV3 | Minor issue, no customer impact | Non-critical alerts, cosmetic issues | Business hours |
